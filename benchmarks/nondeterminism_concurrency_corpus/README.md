# Nondeterminism, concurrency, and flakiness corpus

Dependency-free Python fixtures expose common nondeterministic mechanisms without claiming that
one execution establishes stability. The governed labels separate mechanism discovery from
runtime reproduction and require seeds, schedules, order, platform, interpreter, repetitions,
timeouts, and per-attempt evidence in qualification campaigns.

The bundled cases are regression fixtures. Representative accuracy requires independently
authored external projects, reviewed labels, controlled perturbation, repeated isolated
execution, statistical decision rules, and retained attempt-level evidence.
