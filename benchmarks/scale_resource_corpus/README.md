# Scale and resource-exhaustion qualification corpus

This protocol defines deterministic repository and graph-shape strata for
measuring completion, time, memory, output bounds, graceful degradation, and
semantic equivalence under controlled resource budgets.

Every campaign must retain generator revision and seed, generated tree digest,
environment and dependency digests, CPU/memory/wall-time/output budgets,
repetitions, failures, censored results, phase measurements, and artifacts.
Synthetic shapes are controls; representative external repositories remain
necessary for product performance claims.
